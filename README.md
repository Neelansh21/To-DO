# 📝 To-Do List

A simple and responsive **To-Do List web application** built using **HTML, CSS, and JavaScript**. The application allows users to add, complete, and delete tasks through an interactive and responsive interface.

## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 🚫 Prevent empty tasks from being added
* 📱 Responsive design for mobile, tablet, and desktop
* 🎨 Clean and modern user interface
* ⚡ Interactive UI using JavaScript DOM manipulation

## 🛠️ Technologies Used

* **HTML5** — Structure of the application
* **CSS3** — Styling and responsive design
* **JavaScript** — Functionality and DOM manipulation

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Neelansh21/To-DO.git
```

### 2. Open the project

Navigate to the project directory:

```bash
cd To-DO
```

### 3. Run the application

Open `index.html` in your browser.

You can also use **VS Code Live Server** for a better development experience.

## 💻 How to Use

1. Enter your task in the input field.
2. Click the **Add** button.
3. Click on a task to mark it as completed.
4. Click **Delete** to remove a task.
